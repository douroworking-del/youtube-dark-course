# YouTube Dark Channel — Curso Interativo

SPA moderna e responsiva em **React + Tailwind CSS** para o curso **"Criando um Canal Dark Monetizado no YouTube"**.

## 🚀 Demo ao vivo

Após ativar o GitHub Pages:

**https://douroworking-del.github.io/youtube-dark-course/**

## Como abrir localmente

Basta abrir o arquivo `index.html` no navegador (Chrome, Edge, Firefox, etc.).

Não precisa de instalação, build ou servidor.

## Ativar GitHub Pages (publicação)

1. Vá em **Settings → Pages** do repositório
2. Em **Source**, escolha **Deploy from a branch**
3. Branch: `main` / pasta: `/ (root)`
4. Clique em **Save**
5. Aguarde 1–2 minutos e acesse a URL acima

## Funcionalidades

- **Dark mode** por padrão (zinc/slate + acentos vermelho/ciano)
- **Sidebar sticky** com checklist de módulos e barra de progresso
- **Progresso persistido** em `localStorage`
- **Botão "Copiar Prompt"** com feedback visual (toast)
- **Calculadora de RPM** interativa no Módulo 1
- **Tabelas dinâmicas** de comparação de ferramentas e exemplos
- **Marcar como Concluído** em cada módulo
- Totalmente **responsivo** (mobile + desktop)
- Ícones via **Lucide**

## Módulos

1. Nicho & Validação (Matriz RPM × Escala + Calculadora)
2. Tech Stack (ChatGPT, ElevenLabs, Leonardo.ai…)
3. Scripting & Edição (Regras de retenção, CapCut/Premiere)
4. CTR, Thumbnails & SEO
5. Monetização & Escala

## Stack

- React 18 (CDN)
- Tailwind CSS (CDN)
- Lucide Icons
- Babel Standalone (JSX no browser)
